# Unit AC D0 v4 engineering evidence

This directory records the unconditional Unit AC engineering pass. It creates no
qualification cohort and makes no real-photo, real-fabric, private-user, mobile,
Alpha, Beta, Production, or physical-material capability claim.

The frozen protocol permits at most three complete observation revisions, twelve
complete model trials, and one public-test execution. The committed ledger records
one observation revision, six model trials, and zero public-test executions at the
source-freeze stage. Failed corpus/model/validation artifacts are retained.

The final development route uses a learned 40-feature multiview RGB initializer,
eleven bounded output heads, deterministic source-conditioned fitting, canonical
compilation, and a source-to-panel-UV atlas with per-texel lineage. The primary
selection is a bounded 45% silhouette, 45% direct contour, and 10% learned blend;
target parameters are unavailable at inference.

`development_readiness.json` and `validation_trial_006_final.json` contain the
complete validation gate vector and all 128 rows. `model_card.json`,
`data_card.json`, `trial_inventory.json`, `negative_controls.json`, and
`source_inventory.json` make the development result reconstructable. The
`appearance/representative_091` directory contains persisted PBR preset maps,
compressed per-texel lineage, and front/rear/novel rerenders. These PBR maps are
bounded visual defaults, not inferred physical material properties.

The public-test manifest and capture archive are physically separated from the
development manifest/archive. They are intentionally excluded from the development
source inventory read. The sole public execution may occur only after an exact
source head is committed and pushed, and its claim lock is created before any
public target is read.
