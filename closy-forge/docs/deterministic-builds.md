# Deterministic Builds

Implementation 01 is deterministic by construction:

- fixed fixture timestamp: `2026-01-01T00:00:00Z`;
- fixed default seed: `101`;
- no UUIDv4, wall-clock timestamps, usernames, absolute paths, hostnames, random ordering, or temporary directory names in canonical files;
- canonical JSON uses sorted keys, compact separators, UTF-8, and a trailing newline;
- mesh vertices, triangles, panels, constraints, and inventory entries are emitted in stable order;
- binary binding is fixed little-endian;
- GLB JSON chunks are sorted and generated by Forge code rather than a runtime-dependent exporter.

## Hashes

- Topology hashes include a domain separator, ordered panel IDs, vertex counts, triangle counts, and ordered triangle index streams.
- Content hashes include the topology-relevant data plus positions and panel-space UV coordinates.
- The package digest uses `CLOSY_PACKAGE_DIGEST_V1` over the sorted inventory entries excluding `manifest.json` and mutable reader reports: `reports/package_validation.json`, `reports/summary.json`, and `reports/summary.md`.

The repeated-build integration test builds the demo package into two unrelated directories and compares every relative file hash.
