# Manual-provider C3 development profile v1

This profile evaluates nine independently authored, project-owned dense garment shells: three
T-shirts, three sleeveless tops, and three simple skirts. The sources are CC0-1.0, contain no
personal data, and were frozen before the cleanup, semantic-transfer, binding, or evaluator source
existed. They are not exports from Closy's canonical pattern generators.

The executable path records distinct raw, analyzed, proposed, clean, bound, and packaged asset
identities. It audits raw topology, performs actual deterministic triangle cleanup and structured
surface retopology, transfers explicit panel/opening semantics with confidence and abstention,
builds a lower-resolution simulation cage, and binds every dense render vertex with bounded
barycentric weights. Each package contains independently decodable indexed GLB 2.0 clean and
fallback meshes, rebuilt normals, `TANGENT` `VEC4` accessors, a binary binding, and compressed
float32 production/reference deformation positions.

The locked development denominator is 9 sources by 11 motion states, or 99 rows, with two clean
builds and one final benchmark publication. The reference deformation is a separately implemented
dense-coordinate path; it is still synthetic and is not physical cloth truth. Every source and row
counts, including a cleanup, package, or motion failure.

This evidence can establish only `manual_provider_scoped_C3_development`. It cannot promote a
canonical garment, complete global C3, Phase 5, or Phase 6, or establish real-provider, private-user,
human-visual, mobile/GPU, physical-material, or production readiness. Optional learned/provider
models remain `not_run` when their independently licensed weights or runtime are unavailable.
