## Status Vocabulary

- `not_started`: no implementation path or executable evidence exists yet.
- `scaffold`: contracts, schema, placeholder data or interface shape exists, but the requirement behavior has not executed.
- `partial`: executable behavior exists for a bounded slice, but literal blueprint deliverables, coverage or independent evidence remain incomplete.
- `implemented_unverified`: code exists, but required validation/evidence has not passed or has not been recorded.
- `complete`: implementation, evidence, tests and limitations satisfy the scoped requirement as written in this ledger row.
- `discovery_pending`: required repository, license, authority, hardware or legal facts have not been audited enough to call the item blocked.
- `blocked_external`: an audited external blocker prevents execution and is recorded with owner/evidence.
- `not_applicable`: the requirement is explicitly out of scope for the current package/profile.
