# Simple-Trousers D0 Vertical Slice

This public deterministic Phase 8 fixture proves one literal bifurcated bottom-garment path. The
pattern has four front/back half-leg panels, paired outseams and inseams, front/back rise seams,
one resolved waist opening and independently resolved left/right cuffs. Waist, hip, rise, outseam,
crotch extension, leg gap, cuff width, ease and tessellation are explicit bounded parameters.

The package executes a 25-candidate fit, all four authored Phase 7 material presets, an actual
two-cuff opening stress state, authoritative dense sim-to-render binding, a direct
simulation-topology GLB fallback, decoded PBR maps and independent decoded composite-panel
source/render comparison. Corruption tests reject wrong family/opening semantics, refreshed false
motion claims and damaged binding bytes.

The stress solver records stable cuffs and finite geometry but does not converge under the global
reference-solver criterion. This is project-authored synthetic CPU evidence, not private-user
fitting, measured real-fabric calibration, learned inference, production GPU cloth or mobile
performance evidence. Dresses remain next and Phase 8 remains globally partial.
