# Simple-Skirt D0 Vertical Slice

This public deterministic Phase 8 fixture proves one literal bottom-garment path. The pattern has
front and back skirt panels, left and right side seams, and independently resolved waist and hem
openings. Waist, hip, length, flare, ease and waist-to-hip depth are explicit bounded parameters.

The package executes a 25-candidate fit, all four authored Phase 7 material presets, an actual waist
opening stress state, authoritative dense sim-to-render binding, a direct simulation-topology GLB
fallback, decoded PBR maps and independent decoded source/render comparison. Corruption tests reject
wrong family/opening semantics, refreshed false motion claims and damaged binding bytes.

This is a project-authored synthetic CPU fixture, not private-user fitting, measured real-fabric
calibration, learned inference, production GPU cloth or mobile performance evidence. Simple trousers
remain next and Phase 8 remains globally partial.
